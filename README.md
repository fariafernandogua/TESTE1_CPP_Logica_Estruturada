# 📘 Projetos de Programação em C++

## 📌 Descrição
Este repositório contém vários exercícios em C++ desenvolvidos para prática de lógica de programação, uso de vetores, funções, menus e estruturas básicas de decisão e repetição.

Os exercícios incluem:
- Gestão de alunos e notas
- Sistema de stock de loja
- Ordenação de atletas
- Validação de dados
- Uso de menus interativos

---

## 🧠 Objetivo
O objetivo destes trabalhos é desenvolver habilidades em:
- Lógica de programação
- Estruturas de controlo (if, for, while)
- Vetores e arrays
- Funções em C++
- Manipulação de dados básicos

---

## 👨‍🎓 Exercícios incluídos

### 1. Sistema de temperatud
-digita todas as temperatura de cada dia da semna
-calcula a media da temperatura
-mostra que dia teve maior grau 

### 2. Sistema de alunos
- Registo de nomes e médias
- Lista de aprovados (>=10)
- Cálculo de percentagem de aprovação
- Menu de opções

### 3. Sistema de stock de loja
- Vetores paralelos (código e quantidade)
- Pesquisa por código
- Aviso de “Stock Crítico” (<5 unidades)
- 
### 4. Sistema de atletas
- Ordenação por tempo (do mais rápido ao mais lento)
- Troca de nomes e tempos corretamente
- Validação de dados (tempo não pode ser negativo)
- 
### 6. Supermercado
-armazena nome do produto 
-armazena preço do produto
-guarda esse dados no vetor
